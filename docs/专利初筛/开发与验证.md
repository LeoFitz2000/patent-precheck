# 开发与验证

## 环境和测试

服务使用Python标准库，无数据库、模型SDK、前端构建步骤或pip依赖。代码采用Python 3.10+语法，目前实测环境为Windows / Python 3.14，其他环境应运行测试确认。

```bash
python -m unittest discover -s tests -v
python 专利初筛/app.py --open
```

测试启动随机端口，构造数据写入被忽略的 `tests/.artifacts/运行批次/`。每轮使用独立目录，旧测试材料不覆盖，不调用模型或专利数据库。

## 文件分工

- `专利初筛/app.py`：输入校验、附件解码、不可覆盖的案件目录和HTTP路由。
- `专利初筛/页面.html`：表单、浏览器文件读取、保存反馈和响应式布局。
- `.agents/skills/patent-precheck/SKILL.md`：AI的取证、判断和交付规则。
- 技能内 `agents/openai.yaml`：中文显示信息和自动选择策略。
- `tests/test_intake.py`：真实HTTP及文件保存回归。

## HTTP接口

| 路径 | 方法 | 用途 |
|---|---|---|
| `/` | GET | 材料页面，含本次服务的会话校验值 |
| `/api/status` | GET | 入口标识、工作区和最近案件处理阶段 |
| `/api/cases` | POST | 保存材料；成功返回201及案件ID |

POST JSON字段：`idea`、`goal`、`jurisdiction`、`cutoff_date`、`files`。附件项为 `name` 与Base64 `data`。页面发送本机Origin和会话校验头；服务校验Host、Origin和会话值。

附件合计上限10 MB，HTTP请求上限15 MB，最多8份。先校验再写入，`case.json` 最后创建；没有完整清单的目录不作为已准备案件。附件只作为数据保存，不执行其内容。

`create_server(port=0, data_dir=...)` 可供测试建立独立实例。`--data-dir` 用于测试隔离；正式使用默认目录，避免Agent找错材料。

## 浏览器回归

1. 桌面和约390像素宽度下查看表单，确认无横向溢出、标签可读。
2. 空提交应有提示；仅想法、仅附件、二者同时提供都能保存。
3. 保存后应提示回对话接手，不能显示不存在的模型运行结果。
4. 刷新后能查看最近保存状态；“填写另一份材料”应重新启用空表单。
5. 恢复附件，比对原始字节和清单哈希。

接口测试只证明收件程序行为。语义核查、检索覆盖和专业专利判断需要另外验证，不能以页面测试代替。

## 修改与提交

代码、Skill和项目文档进入Git；真实材料、处理记录、截图和历史实验输出默认不提交。提交前检查 `git status` 与 `git diff --cached`，确认范围。

已有报告和案件输入不因代码修改而覆盖。`.cmd` 保留CRLF换行；`.gitattributes` 维护Windows启动文件换行。不要把本机Python路径、账号令牌或真实案件写进示例。
