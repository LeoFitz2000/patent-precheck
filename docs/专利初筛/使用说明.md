# 使用说明

## 直接在对话里使用

在支持项目技能的AI客户端打开本仓库，描述技术想法或提供附件，说“帮我初筛”。规则位于 `.agents/skills/patent-precheck/SKILL.md`，不需要填写内部评审字段。

AI先沿用已给信息，只有缺口会改变方向时才提出少量选择题。没有样机、尺寸或完整术语，不会自动阻止先整理公开技术。

## 需要填写提示时

1. 运行 `python 专利初筛/app.py --open`，或在Windows双击 `专利初筛/打开材料入口.cmd`。
2. 打开 <http://127.0.0.1:51919/>，描述想法或选择附件。
3. 用途可保留默认选项；地区和资料日期知道再填。
4. 点“保存材料”，看到完成提示后，在对应工作区对话说“开始初筛”。

页面只保存材料，不会自行调用模型。保存后本次表单锁定，点“填写另一份材料”可新建一份，不覆盖已保存案件。

附件支持PDF、DOCX、TXT、MD、PNG、JPG、JPEG，最多8份、合计10 MB。原始文件被保留，不表示页面已经解析或看懂附件。

## 材料和结果在哪里

每次提交创建 `专利初筛/材料/案件-时间-随机标识/`，其中包含：

- `case.json`：实际填写的想法、用途、地区、日期与附件清单。
- 原始附件：名称经过路径清理并带序号，内容字节和SHA-256保留。
- `结果/运行-时间戳/`：由Agent执行后写入，收件阶段没有结果。

Agent在 `专利初筛/运行记录/处理记录.jsonl` 追加阶段事件。网页显示“等待对话接手”只说明保存成功；只有实际执行并记录后才显示后续状态。

这些运行时目录均被Git忽略。请另行备份有价值的案件，不能依靠代码仓库恢复被忽略的材料。

## 启动与关闭

- 前台运行：`python 专利初筛/app.py`，在该终端按 `Ctrl+C` 停止。
- 打开浏览器：加 `--open`。
- 修改端口：例如 `python 专利初筛/app.py --port 51921 --open`。
- 相同工作区、相同端口已有服务时会复用已有服务。

Windows双击入口隐藏服务窗口；关闭浏览器页面不会停止服务。需要明确控制服务生命周期时，使用前台命令启动和停止。服务只绑定本机地址。

## 常见情况

| 情况 | 处理方式 |
|---|---|
| 页面打不开 | 先运行启动命令，确认Python可用、端口没有被其他应用占用 |
| 直接打开HTML后不能保存 | 通过启动脚本或Python服务打开页面 |
| 保存失败 | 保留页面内容，检查文件格式、数量和大小，刷新后重试 |
| 截止日未填 | AI按实际检索时点说明范围，不当作申请日期 |
| 目标地区未确定 | 可先整理公开技术，涉及法域判断前再澄清 |
| AI未读取附件或未联网 | 应明确缺口，不应声称已完成查新 |

用户提供实际材料并选择用途与投入；AI承担原文核查、未知管理和后续计划，不对用户知识评分。
